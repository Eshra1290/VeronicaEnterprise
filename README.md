This is a Worker Management System designed to help management efficiently manage workers' attendance, task assignments, and task progress. Its main feature is QR code-based attendance tracking, which allows workers to scan a QR code displayed on the admin dashboard to check in. Other features include task scheduling and report generation.
## Project Demo Video

This video demonstrates the features and functionality of the Worker Management System, a web application developed for private organizational use.

The website allows registered workers to access their dashboards to view task assignments and manage their attendance, while administrators can manage workers, task details and report generation.

**Technologies used:** PHP, MySQL, HTML, CSS, JavaScript.
